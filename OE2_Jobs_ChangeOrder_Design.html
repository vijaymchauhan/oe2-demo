What's Changing — Overview
Two targeted changes to the existing Jobs Detail screen and Change Order Log report, based on the May 27 meeting discussion:
  • Change 1 — P/O Status Column on AP Run (Billing grid): When a Proposal is created for an existing AP number it automatically appears on the AP run as a P (Proposed) row. Once approved/converted it becomes O (Approved). P rows are highlighted amber so they stand out. This ensures every priced extra — even before GC approval — is visible on the billing review.
  • Change 2 — "Include P" checkbox on Change Order Log: A new checkbox ☐ Include P appears next to the View Change Order Log link. Unchecked (default) = shows only O (approved) extras, same as today. Checked = shows both P and O, so the team can review all priced extras and follow up on approvals.
Why: Currently, proposals for extras are being written but never entered into the system because no one confirmed GC approval. By showing P-status extras on the AP run, the billing review meeting becomes: "We priced these items — which ones did you actually do?" — and they can be bulk-approved or closed from the Proposals tab.
