Screen 2 — Create / Add Proposal
📌 Opened when user clicks the Add tab. Customer can be an existing customer (lookup) or a prospect (free-text name entry). Status: Draft / Sent / Approved / Rejected.   Type: New / Revision / Change Order. Proposal # is auto-generated (e.g. 10004.00).

Screen 3 — Edit Proposal (with Action Buttons)
📌 Opened when user clicks a Proposal# link from the listing grid. Edit screen adds an action toolbar with: New Revision · Convert to Job · Print · Email. "Convert to Job" is only enabled when Status = Approved.

Screen 4 — Convert to Job (Modal Dialog)
📌 Clicking Convert to Job opens this modal overlay on the Edit screen. User selects which proposal items to include in the Job's billing, and enters the Customer Job # (new field). On confirm, a new Job record is created with the selected items pre-populated.
