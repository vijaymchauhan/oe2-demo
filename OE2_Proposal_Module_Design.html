📋   How the Proposal Module Works — End-to-End Flow
1
✏️
Create Proposal
Open the Proposal tab and click Add. Choose Existing Customer, Prospect (New), or Existing AP (Extra). Fill in job details and add line items. Saves as Draft.
2
📤
Send to Customer
Click Print or Email on the Edit screen. Status updates to Sent. For extras linked to an AP, the proposal appears on the AP run immediately as P (Proposed).
3
🔄
Revise if Needed
If the customer requests changes, click New Revision. A copy is created with the next revision number (e.g., 10000.01). The prior version is kept for history.
4
✅
Customer Approves
For new jobs: status becomes Approved and Convert to Job is available. For extras: use Approve Extra to change status from P to O on the AP run.
5
🔄
Convert / Approve
New jobs: Click Convert to Job, select items, enter the Agreed Amount. One job is created with the combined description. Extras: Click Approve Extra — status changes to O on the AP run.
6
📁
Job(s) Created
New Job appears in the Jobs module with billing details pre-filled. Extras update status to O on the existing AP run and are ready for billing.
📌 Proposal Numbering
  • New proposals are auto-numbered starting at 10000.00
  • Each revision increments the decimal: 10000.01, 10000.02…
  • The base number groups all revisions together in the listing
  • Proposal numbers and Job numbers share the same sequence
📌 Convert to Job — How it Works
  • Select the line items to include in the job
  • All selected item descriptions are combined into one job description (auto-merged, editable)
  • Enter the final Agreed Amount (the negotiated price — may differ from the proposal sum)
  • Creates 1 Job record with the combined description and agreed amount
📌 Status Meanings
  • Draft — Proposal is being prepared, not yet sent
  • Sent — Delivered to customer, awaiting response
  • Approved — Customer accepted; Convert to Job available
  • Rejected — Customer declined; proposal is closed
  • P (Proposed) — Extra on an AP run, not yet approved
  • O (Approved) — Extra approved and ready for billing
📌 Proposal Types
  • Existing Customer — New job proposal for a customer already in OE2
  • Prospect (New) — New job proposal for a customer not yet in the system
  • Existing AP (Extra) — Proposal for an extra on an existing AP job. Added to the AP run immediately as P. Bulk-approve to change to O when the customer confirms
Screen 1 — Proposal Listing Page

What this screen does

This is the main entry point for the Proposal module. It shows all proposals in a searchable, scrollable grid. Users can search by Proposal #, AP #, Customer Name, Customer Job #, Customer PO #, or Project Manager. Extra proposals linked to AP jobs are highlighted and show the AP # column with their P/O status.


How to use it

  • Use the Search Proposals sidebar to filter. Enter one or more fields and click Search. Click Clear to reset.
  • Search by AP # to see all proposals (extras) linked to a specific job.
  • Click any Proposal # link (in dark red) to open that proposal for editing.
  • Select multiple rows using checkboxes and click Bulk Approve to approve all selected extra proposals at once.

Grid columns explained

  • Proposal # — Format NNNNN.RR. Click to open and edit.
  • AP # — Linked job number for extras (blank for new job proposals).
  • Status — Draft Sent Approved Rejected or P – Proposed / O – Approved for extras.
  • Total ($) — Sum of all line items (auto-calculated).

Screen 2 — Create / Add New Proposal

What this screen does

Used to write a new proposal for a customer, prospect, or an existing AP job (extra). The system auto-assigns the next Proposal Number. The user fills in job details, adds line items with pricing, and the total (including tax) is calculated automatically.


Step-by-step: How to create a proposal

  • Step 1 — Choose Type: Existing Customer (use Lookup), Prospect (New) (type name), or Existing AP (Extra) (select the AP# — proposal is added to that job's AP run immediately as P – Proposed).
  • Step 2 — Set CPC: Select the Customer Project Contact (the "ATTN:" person on the printed proposal). This field is right next to the customer selector.
  • Step 3 — Fill in Job Details: Enter Job Name, Floor, Address, City, State, Zip.
  • Step 4 — Status & Tax: Status starts as Draft. Select Tax Code. The Valid Until Date auto-fills to 1 year from the proposal date — edit if needed.
  • Step 5 — Add Line Items: In the Proposal Items section, click + Add New Item. Enter Item Name, Description (large text box for detailed scope), Quantity, and Unit Price. Check ALT * for alternate items. Tax and total are auto-calculated at the bottom.
  • Step 6 — Exclusions: Enter standard exclusions below the items table.
  • Step 7 — Save: Click Save Proposal.

Key field notes

  • PM/Biller and PE are required (*). PE name prints as the Estimator/signer on the proposal.
  • CPC — Customer Project Contact. Prints as "ATTN:" on the proposal. Shown next to the Customer field.
  • Valid Until Date — Auto-set to +1 year from proposal date. Always editable.
  • ALT * checkbox — Marks an item as an Alternate; excluded from the main subtotal on the printed proposal.

Screen 3 — Edit Proposal (Action Buttons)

What this screen does

Same form as Create Proposal, opened by clicking an existing Proposal # from the listing. Shows an Actions toolbar at the top that drives the full proposal lifecycle.


Action buttons explained

  • 📄 New Revision — Creates a copy with the next revision number (e.g., 10001.01). The current version is preserved as a read-only historical record.
  • 🔄 Convert to Job — Opens the Convert to Job dialog. User selects items, verifies the combined description, and enters the Agreed Amount. Creates one Job record. See Screen 4.
  • 🖨️ Print — Generates the formatted Albert Pearlman proposal document. All fields auto-populate from the proposal record.
  • ✉️ Email — Opens Outlook with the proposal PDF attached and customer details pre-filled.
  • 📋 Clone Proposal — Copies all proposal details (line items, job name, dates, assignments) except the customer name — left blank for the user to select. A new proposal number is assigned. Used when quoting the same scope to a different GC/customer.

Screen 4 — Convert Proposal to Job (Modal)

What this screen does

Opens when the user clicks Convert to Job on an Approved proposal. The user selects which line items to include, reviews the auto-combined description, and enters the final Agreed Amount (the negotiated price). One Job record is created.


How to use it

  • Step 1 — Check the items to include. Uncheck any items the customer did not approve (e.g., ALT items not accepted).
  • Step 2 — Review the Combined Job Description — the system merges all selected item descriptions. Edit the text if needed.
  • Step 3 — Enter the Customer Job # and the Agreed Amount (the final negotiated price — this may differ from the proposal sum if the customer negotiated a different price).
  • Step 4 — Review the Job to be Created summary and click Create Job.

Screen 5 — Proposal Print Preview

What this screen does

Clicking Print on the Edit screen opens a formatted, print-ready proposal document matching the standard Albert Pearlman proposal format exactly. All fields are automatically populated — the user does not need to re-enter anything.


How fields map from OE2 to the printed proposal

  • ATTN — From the CPC (Customer Project Contact) field
  • Company — From the Customer Name (or Prospect Name) field
  • Address / City, State, Zip — From the Job Address fields
  • Date — From the Proposal Date field
  • WO# / PO# — From the Customer PO / Change Order # field
  • Customer Job # — From the Customer Job # field
  • AP# — From the Proposal # (e.g., 10001.00)
  • Estimator — From the PE field (Project Estimator — required)
  • Line items — Each row from Proposal Items with its Amount. Description from the item's Description textarea.
  • ALT * column — Items with ALT checked are flagged; their amount is excluded from the Subtotal
  • Exclusions / Notes — From the Exclusions / Notes field (printed below the items table)
  • Subtotal / Tax / Total — Auto-calculated: Subtotal = sum of non-ALT items; Tax = Subtotal × Tax Code rate; Total = Subtotal + Tax
