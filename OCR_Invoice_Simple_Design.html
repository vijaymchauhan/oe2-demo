How It Works — Simple Overview
4-step process, no complexity:
  • Step 1 — Drop files: Vendor PDFs/images placed in a watched folder on the server. Windows Service picks them up automatically every few minutes.
  • Step 2 — OCR reads the invoice: System extracts Vendor Name, Invoice#, Date, AP/PO Number, Total. Each field gets a confidence score.
  • Step 3 — User reviews: Open the invoice, check highlighted fields (especially the AP/PO Number), correct if needed, click Approve.
  • Step 4 — Links to OE2: Approved invoice is linked to the matching OE2 job. File moved to Completed folder automatically.
⚠ AP/PO Number is critical — each vendor labels it differently: Deluxe = "RO No.", Sherwin-Williams = "PO#", Merit = "PO Number:", Janovic = "PURCHASE ORDER:", Eastern/Aboffs = "PO:". Always verify this field before approving.
