How It Works — Simple Overview
4-step process, no complexity:
  • Step 1 — Drop files: Vendor PDFs/images placed in a watched folder on the server. Windows Service picks them up automatically every few minutes.
  • Step 2 — OCR reads the invoice: System extracts Vendor Name, Invoice#, Date, AP/PO Number, Total. Each field gets a confidence score.
  • Step 3 — User reviews: Open the invoice, check highlighted fields (especially the AP/PO Number), correct if needed, click Approve.
  • Step 4 — Links to OE2: Approved invoice is linked to the matching OE2 job. File moved to Completed folder automatically.
⚠ AP/PO Number is critical — each vendor labels it differently: Deluxe = "RO No.", Sherwin-Williams = "PO#", Merit = "PO Number:", Janovic = "PURCHASE ORDER:", Eastern/Aboffs = "PO:". Always verify this field before approving.
Screen 1 — Invoice List (Main Screen)
The everyday working screen. Shows all vendor invoices detected from the folder. Use the left filters to narrow down by status. Click an invoice row to open it for review.

Key columns added:
  • Invoice Address — The ship-to / job-site address extracted by OCR from the invoice.
  • OE2 Job Address — The job address on file in OE2 for the matched AP number.
  • Floor — Floor from OE2 for the matched AP job.
  • If the invoice address does not match the OE2 job address, the row is flagged ⚠ Addr Mismatch and automatically sent to Review Required.
  • Invoices over $1,500 are flagged with ⚠ $1,500+ for extra attention.
  • Approved invoices show a 🔗 PDF link to view the original invoice file at any time.

Screen 2 — Invoice Review & Edit
Opens when you click an invoice row. Shows what OCR extracted from the vendor PDF. Fields with red border = low confidence — must verify. Orange border = medium confidence — check before approving. The AP/PO Number is always shown prominently since it links the invoice to the correct OE2 job. Once fields look correct, click Approve.

Address Comparison panel — side-by-side view of the Invoice Address (extracted by OCR from the invoice) vs the OE2 Job Address (pulled from the matched AP number). If they don't match, a red ⚠ warning is shown and the invoice is flagged Review Required. The Floor field from the OE2 job is also shown here. OE2 fields are read-only; correct the AP# if the wrong job was matched.
A 🔗 View Original PDF button is always visible so the reviewer can check the raw invoice at any time.
